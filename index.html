The 6-Step Factory Loop

1

Environment Discovery

Databricks MCP enumerates live catalogs, schemas, tables, warehouses — no hardcoded paths.

2

Rule Extraction

The AI agent reads deduplication business rules from the existing documentation and logic, then maps each rule to a structured test scenario category covering whole-block, cross-block, fuzzy, exact, alias, false positive / negative, and operational patterns.

3

Scenario & Workbook Alignment

Test scenarios are aligned to the Excel workbook package — cases, expected outcomes, and ground-truth labels are seeded automatically, ready for the validation run.

4

Validation Execution

Four targeted validation scripts run against live silver tables: duplicate rule correctness, fuzzy-match boundary behaviour, false positive / negative detection, and end-to-end pipeline integrity.

5

Results & Workbook Sync

PASS/FAIL results written to the execution tracker and automatically synced to the Excel workbooks — no manual data entry after the run.

6

Automatic Jira Defect

On any failure the AI agent raises a Jira bug in the agreed engagement project, with auto-applied labels and the ticket ID written back to the tracker — closing the loop without copy-paste.
